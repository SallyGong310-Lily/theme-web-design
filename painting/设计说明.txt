余色 AFTERIMAGE｜光的三种停留

品牌命题
一间以「慢看」为核心的线上绘画馆。面向想欣赏绘画、又不想先背艺术史的访客。
情绪从安静、感知，到主动选择；让作品成为首屏主角，让文字为观看留出空间。
本次为新建概念品牌与编辑选集，非博物馆官网重设计。

视觉语言
暖纸白 #F3F0E8 / 墨黑 #292C27 / 朱砂红 #A83C2D。
正文灰 #66695F / 边界灰 #D0CFC4 / 细节区底色 #E7E5DB。
大宋体标题与细小无衬线目录构成阅读张力；左文字、右画幅的非对称构图，
配合细线、竖排编号、红色圆印章与罗马序号，呈现展览图录的秩序感。
避免把每段内容都塞进卡片；画面边缘、分隔线与留白本身就是信息边界。
桌面左右页边 60 px，手机 22 px；使用 12 / 16 / 24 / 32 / 48 / 64 px 的间距节奏。

信息层级
1. 余色品牌 + 本期目录：交代是谁、现在看到什么。
2. 主张与大幅画作：先建立感受，再给出一条清晰的「进入画作」路径。
3. 三个章节：水光 / 海风 / 夏日，提供有限且容易理解的选择。
4. 本期作品：看到全部选项，直接打开任何作品的详情。
5. 观看方式：从整体、细节到收藏，给非专业观众一个轻量起点。
6. 观展单：把浏览转化为本地留存和随身导出，无需登录。

转化路径
首屏被画作吸引 → 查看完整作品 → 加入观展单 → 再选一幅 → 导出清单。
主按钮为朱砂色，次级浏览路径用下划线，收藏状态即时反馈。
空清单提供「去挑选一幅画」，避免访问者停在没有下一步的空状态。

交互节奏
切换采用 860 ms 的横向 clip-path 遮罩揭幕，手动选择优先；连续点击会清理旧动画。
自动播放为用户主动开启，每幅停留 7 秒；阅读和后台状态自动暂停。
图像视差最大约 7 px，印章反向约 4 px，滚动细节图最大 10 px。
整个页面不依赖动态效果理解内容；系统减少动态效果时立即切换静态状态。

响应式与可达性
700 px 以下转换单栏，保留完整作品列表、清单入口与全部交互。
主按钮与轮播控制至少约 44 px 高；真实 button / nav / main / dialog 语义。
可见焦点、跳过导航、轮播状态播报、键盘左右与首尾跳转、弹窗焦点恢复。
图像替代文本区分裁切预览与完整作品。没有仅靠悬停才能访问的功能。

交付与边界
HTML 独立离线运行；SVG 保留文字与矢量对象，并含原生 Figma 重建元数据。
SVG 和 HTML 的图像均为馆藏位图，绘画的颜料笔触本身不是矢量图形。
PNG 是浏览器渲染预览；动效请在 HTML 中体验。
本地 Figma 导入器使用官方 Text / Shape API；目标设备字体可能影响基线与字宽。
