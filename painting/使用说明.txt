2026-10-01 · 全新概念 01「光的三种停留」

一、快速开始
解压 ZIP 后，双击「余色-交互原型.html」，使用 Chrome、Edge 或其他现代浏览器打开。
CSS、JavaScript 和三幅馆藏图片均已内嵌，单独复制这个 HTML 文件也能离线运行。
无需安装依赖、启动服务器、填写账号或连接网络。

二、交互方式
• 首屏左右箭头、三个章节按钮均可切换画作；手机可左右滑动图片。
• Tab 将焦点移入画作轮播后，← / → 切换，Home 回到首幅，End 到最后一幅。
• 「进入画作」、画作右下角 ↗ 或下方作品卡片打开详情，查看完整画幅。
• 在详情里加入观展单；右上角打开清单，可以移除作品或导出 TXT。
• Tab / Shift+Tab 移动焦点，Enter / Space 激活按钮，Esc 关闭弹窗并返回触发位置。
• 默认不自动播放；主动开启后每 7 秒换一幅。悬停、焦点进入展区、切至后台或打开弹窗时暂停。
  点击后如希望观察自动播放，先把指针和键盘焦点移出首屏展区。
• 桌面指针带动画作与印章以相反方向微移，滚动时下方细节图独立视差移动。
• 系统设置「减少动态效果」会关闭遮罩动画、视差、平滑滚动和自动播放。
  页脚也可手动关闭动态效果；系统减少动态效果的偏好优先。
• 观展单仅使用当前浏览器的本地存储；隐私模式或存储受限时保留本次会话，并提示导出。
  这是可运行的概念原型，没有联网账号、支付或预约后台。

三、Figma：保持文字可编辑
交付两张设计稿：桌面 1440 px、手机 390 px，均为全页 SVG。
SVG 使用真实 <text> 文字和独立矢量元素，不是把整页截图装进 SVG；绘画本身是嵌入式馆藏位图。
SVG 可直接拖入 Figma。不同 Figma 导入版本可能将 SVG 的文字轮廓化。
若需要逐字编辑，请使用附带的「Figma文字可编辑导入」本地开发插件：
1. 在 Figma 桌面版打开设计文件，选择 Plugins → Development → Import plugin from manifest。
2. 选择「Figma文字可编辑导入/manifest.json」。
3. 运行「余色 SVG · 原生文字导入」，选择本包的桌面或手机 SVG，点击「导入到当前页面」。
4. 导入器读取 SVG 内的布局元数据，创建原生 Text、Rectangle、Line、图像填充与裁切 Frame。
   每行文案可直接编辑；图像可替换；色块、线条、边界可继续调整。
5. 使用本机 Georgia、宋体（SimSun）及 Microsoft YaHei。缺字库时工具会回退并报告替代字体。
   建议安装含中文的字体后导入，避免替换导致行宽或基线轻微变化。
如 Figma 要求生成开发插件 ID，请通过 Development → New plugin 创建本地插件，保留生成的 ID，
再将本包的 code.js、ui.html 与 manifest 的其余配置复制到该插件目录中运行。
插件全程不访问网络，不调用付费服务。
本次已检查 SVG 结构、浏览器渲染与导入器代码；未在登录的 Figma 客户端执行实机导入。
Figma 文本 API：https://developers.figma.com/docs/plugins/working-with-text/
Figma 插件配置：https://developers.figma.com/docs/plugins/manifest/

五、关于素材
三幅 Claude Monet 画作来自芝加哥艺术博物馆公共领域馆藏，API 均标记 is_public_domain=true。
来源与 CC0 证据保存在 assets/source-*.json 及「素材授权与来源.txt」。
界面没有把馆藏画作宣称为原创作品，也不代表博物馆的官方服务。
原始 JPEG 保留完整画幅，页面中的裁切仅服务于排版。

六、验收范围
原型在本机 Google Chrome 中通过桌面、390 px 与 320 px 布局及交互检查。
包含轮播、快速连续切换、遮罩、视差、自动播放/暂停、键盘、Esc 焦点返回、
弹窗焦点限制、本地保存、导出下载、系统减少动态效果、无外部网络请求检查。
完整机器可读结果见「验收记录.json」。其他浏览器与 Figma 实机仍需目标环境验收。
