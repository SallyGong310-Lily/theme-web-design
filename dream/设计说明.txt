ONEIRA / 梦境漫游档案馆

设计命题
把梦境理解为“给现实留一道温柔的出口”。品牌是一座可以被个人收藏的内心风景档案馆，情绪为宁静、疏离中的归属感与缓慢的好奇心。

独立视觉语言
暖纸色 #F3F0E7：阅读底色与现实世界；深墨绿 #213B34：界面秩序；赤陶 #B56A4F：门槛、选择与交互提示。三幕场景分别使用赤陶、橄榄和青灰色主题。
拱门既是品牌标记，也是跨越状态的隐喻。漂浮岛、没有承重的楼梯与水面月档案构成三幅原创场景；使用明确可编辑的几何体、有限色阶及细线水纹，避免依赖照片或素材库。
中文宋体标题承担情绪，英文衬线短句提供停顿，正文及微型档案编号建立信息秩序。桌面采用左侧叙事、右侧主视觉的大比例非对称布局；移动端按叙事—行动—场景顺序排列。

信息层级与转化路径
第一层：品牌与一句情绪承诺“把清醒留在岸边”。
第二层：明确的“进入这场梦”行动，以及可选择的当前场景。
第三层：三张场景卡片，把选择从抽象概念转为当下情绪。
第四层：进入场景、留下心情、保存私人收藏。无需登录即完成一次轻量转化。
导航提供“梦境漫游”和“我的梦境”，同时保留“关于梦境”锚点；没有无去向的购买按钮或虚构数据。

交互节奏
轮播手动控制，不自动推进；遮罩揭幕为 800ms，三个视差层级系数为 0.3 / 1.1 / 1.8；指针离开后归位。
三条进度指示、场景编号、视觉与文案同步更新，屏幕阅读器可获得当前场景变化。
弹窗可收藏或继续下一场梦，原生 dialog 提供焦点限制及 Escape 退出。
系统减少动态效果开启时，动画与视差停止，全部功能仍可操作；页脚手动开关可额外关闭动态。

版式参数
桌面基准宽度 1440，边距 64，左侧叙事占 45%，右侧场景占 55%；场景卡片间距 27。
手机左右边距 22，标题约 54，场景容器高度 490；支持 320px 起的窄屏布局。
原型采用系统字体栈，文件中不包含任何未授权字体。

验证范围
已在本机 Edge 的无界面浏览器中运行 14 项功能与结构检查；已目视检查桌面、手机和 SVG 预览。
测试覆盖 320 / 390 / 768 / 1024 / 1440px，无横向溢出；页面运行无 JavaScript 错误，无 HTTP 网络请求。
Figma 真实客户端导入和其他浏览器尚未实测；手机触屏行为通过合成事件验证，未在实体手机上测试。
