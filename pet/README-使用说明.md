# MELLOW 尾伴｜宠物网页概念设计

## 打开与编辑
- 双击 `index.html`，即可离线运行。CSS、JS 和全部插画均内嵌，不需要安装依赖或联网。
- 将 `design-desktop-dog.svg` 拖入 Figma，即得到 1440 × 1940 桌面设计稿；另有猫咪、兔兔两个轮播状态，以及 390 × 2470 移动设计稿。
- SVG 使用原生 text、path、rect、ellipse、circle；文字没有转轮廓，插画没有栅格化。导入后可编辑文本与矢量节点。没有 Figma 在线账号验证环境，本次通过 SVG 结构和浏览器渲染验证可编辑性。
- 字体为 Georgia / Arial / Microsoft YaHei。目标设备缺少字体时，在 Figma 选择本机已安装字体替换；行宽可能略有变化。没有打包或分发商业字体文件。
- `preview-desktop.png`、`preview-mobile.png` 为真实原型截图；`preview-design.png` 为矢量设计稿预览。响应式原型与固定尺寸稿保留相同视觉系统，实际换行和下方模块高度随设备变化。

## 交互
- 点击左右箭头或进度条切换狗狗 / 猫咪 / 兔兔；手机可横向轻扫插画。
- 将键盘焦点移入轮播后：← / → 切换，Home / End 跳至首 / 末张。Tab 导航，Enter / Space 激活按钮。
- 点击“开启陪伴提案”，选择伙伴和相处节奏，生成相应灵感；可重新选择。弹窗内可用 Tab，按 Escape 关闭并返回触发按钮。
- 三张日常卡片的右下角箭头可打开细节；导航和回到顶部为本页锚点。
- 轮播通过 CSS clip-path 实现圆形揭示和横向遮罩过渡；背景圆环、宠物与浮签分别响应指针及滚动，形成不同位移深度。
- 尊重系统 `prefers-reduced-motion: reduce`：关闭遮罩动画和视差，仍保留即时切换及全部功能。轮播不自动播放，节奏由用户掌控。

## 设计逻辑
情绪：慢下来、亲密、轻微野趣。品牌：MELLOW / 尾伴，为宠物家庭提供日常陪伴灵感的虚构概念品牌。
视觉：深李紫 #392C40、奶油白 #F8F5ED、酸橙绿 #D7EB77、暖杏色 #EFC4AA。大字号衬线英文建立情绪，中文无衬线承担理解与行动；拱形场景与纸雕感矢量插画形成识别。
层级：首屏情绪与行动入口 → 三种宠物场景 → 三个可阅读的日常细节 → 个性化陪伴提案。
转化：所有主要按钮汇入同一份两题提案，提交后直接展示对应内容，不收集个人信息，不模拟预约、购买或邮件发送成功。
节奏：用户触发的 660ms 遮罩换场；轻微分层视差；内容区域静态阅读；减少动态效果模式完全关闭动效。

## 图片与授权
`assets/dog.svg`、`assets/cat.svg`、`assets/rabbit.svg` 为本次从零绘制的原创矢量插画，代码、设计与插画均随项目交付。没有第三方照片、远程图片、图库占位或外部网络请求。可随本设计编辑和使用；虚构品牌用于概念展示。
