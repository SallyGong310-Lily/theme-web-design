三、交互操作
1. 点击章节标签或左右箭头切换三段旅程；轮播不会自动播放。
2. 将焦点移至首屏轮播或其中的按钮后，左右方向键切换；Home / End 跳到首尾。
3. 触屏可横向滑动切换，纵向滑动仍用于阅读页面。
4. 鼠标移动与页面滚动分别驱动海流、定位环、文字标注的分层视差。
5. 切换画面使用约 1.05 秒的横向遮罩揭示；动画期间不叠加新的切换。
6. 开启系统“减少动态效果”后，立即切换章节，取消遮罩动画、视差与平滑滚动。
   页尾也有手动减少动态效果开关；系统设置优先。
7. 点击“探索这段旅程”或航线箭头打开详情，再进入预约表单。
8. 填写称呼与有效格式的邮箱后生成本地预约卡，可下载 TXT。
9. Tab 顺序移动焦点，Enter / Space 激活按钮，Esc 关闭弹窗并恢复触发位置的焦点。
   原生 dialog 管理弹窗内焦点；页面还提供“跳转到主要内容”链接。

四、Figma 导入与文字编辑
SVG 使用标准 text、path、circle、rect 与渐变，不含整页截图或 foreignObject。
文字没有转曲；原始 SVG 中的文案与矢量路径均保持独立、可编辑。
可将两份 design-*.svg 拖入 Figma，再取消组合，编辑图形与布局。

如果当前 Figma 的 SVG 导入流程将文字转成轮廓，请使用附带的原生文字导入方式：
1. 在 Figma 桌面版打开一个设计文件。
2. 从 Plugins → Development → Import plugin from manifest，选择
   figma-editable-import/manifest.json。
3. 运行 PELAGIC · Editable artboards。
4. 两张画板会一并导入：图形通过 SVG 导入，文案以原生 Text 图层创建。
   辅助插件不联网，也不修改既有图层；字体缺失时会选取可用字体。

推荐本机具备 Georgia、Arial、Microsoft YaHei；macOS 可使用 PingFang SC。
未随包分发商业字体文件。字体替换可能造成字宽与基线的小幅差异，请导入后复核。
本次验证了 SVG XML、浏览器渲染、原生 text/path 数量以及插件 JavaScript 语法；
未进入真实 Figma 编辑器执行导入，因此不将 Figma 内部表现标记为已实测。
Figma API 依据：
https://developers.figma.com/docs/plugins/api/properties/figma-createtext/
https://developers.figma.com/docs/plugins/api/properties/figma-loadfontasync/

五、设计意图
情绪：克制、好奇、静谧。用海流等深线表达海洋的运动，不依赖常见海滩图库。
品牌：虚构的海洋文化与探索品牌 PELAGIC / 深蓝档案。
配色：暖白 #F4F3EC、深海蓝 #062633、墨色 #132C36、航标黄绿 #D5ED93。
      第二、三章节分别引入浅青与雾紫，维持同一套航海仪器式标注语言。
排版：英文衬线大标题建立情绪，中文无衬线承载内容，细小坐标标注控制节奏。
层级：首屏情绪与章节 → 品牌主张 → 三条航线 → 单一预约入口。
转化：认识旅程 → 查看详情 → 选择旅程 → 本地预约卡，保持完整且轻量的反馈闭环。
响应式：桌面为宽幅构图，移动端重排标题、海流与导航，避免直接缩小桌面画面。
静态 SVG 与响应式 HTML 共享视觉系统；排版高度会随浏览器字体和断点变化。

用户要求的交付邮件由本次任务单独发送，与网页预约演示无关。
