AFTERHOURS / 夜航档案 — 赛博朋克网页概念设计

1. 打开 index.html 即可离线运行，无需安装、联网或启动服务器。CSS、JS 和三张原创 SVG 图片全部内嵌。assets 文件夹提供独立矢量原图。
2. 左右箭头、01–03 编号和城区卡片均可切换轮播；焦点在主视觉内时，← / → 切换，Home / End 跳至首尾。Tab 可遍历控件，Enter / 空格激活按钮，Esc 关闭弹窗。
3. 自动播放默认关闭，开启后每 6.5 秒切换。手动切换、鼠标进入主视觉、焦点进入主视觉、切换后台及打开弹窗时暂停。系统 prefers-reduced-motion 开启时禁用自动播放、遮罩动画和视差，仍可手动切换。
4. 鼠标移动可观察远景、建筑和前景不同深度的视差。切换时采用水平遮罩过渡。触屏不启用指针视差。
5. “开启夜航 / 获取通行证”打开当前城区的通行证表单；输入代号后生成并下载本地 TXT。无真实预订、不采集邮箱、不上传个人信息。
6. 将 AFTERHOURS-desktop-editable.svg 拖入 Figma。文字为原生 text 元素，城市、轨道、标记、卡片均为矢量图形，无截图替代。取消分组后编辑。使用 Arial / Microsoft YaHei；其他系统请替换为 Noto Sans CJK SC 等中文字体，检查字宽。部分 Figma 导入流程可能将描边文字的显示效果简化，可为 HOURS. 手动恢复 1px 骨白描边。
7. preview-desktop.png、preview-mobile.png 为实际 HTML 渲染截图；preview-svg.png 为 SVG 设计稿渲染。设计稿是桌面静态基准，HTML 提供响应式与交互状态。

设计逻辑
品牌：虚构的独立夜行文化档案。情绪：克制、疏离、自由探索。
视觉：骨白巨型字标 + 冷绿机械建筑 + 信号橙轨道；细线坐标、留白和编辑式信息布局形成层级。另两区以荧绿和冰蓝切换频率。
路径：主视觉建立气氛 → 三个城区区分兴趣 → 路线选择 → 本地通行证反馈。
节奏：默认静态阅读 → 主动切换触发 700ms 遮罩 → 指针微视差 → 模态表单集中决策。
颜色：背景 #101917；正文 #EBECE0；辅助 #A7B5AB；信号 #FF6B35；线框 #39463F。

原创与授权
全部图形由本次项目通过代码原创绘制，没有外链、第三方图片或品牌素材。可随本项目使用、修改与继续开发。系统字体不随包分发；使用本机已授权字体。AFTERHOURS 名称及全部场景仅用于概念展示，未作商标清查。
